#HCI-Porject
This Human-Computer Interaction project centers on creating an intuitive system for exploring monuments within an augmented reality (AR) environment, driven entirely by hand gestures. At its core, the system employs advanced computer vision algorithms to continuously track and precisely interpret a user's hand movements in real-time. These recognized gestures, such as pinching to zoom or swiping to rotate, are then translated into specific commands for interacting with the virtual monument. The computer vision pipeline handles everything from pose estimation to gesture recognition, ensuring a fluid and responsive user experience. Ultimately, this project leverages the power of vision-based gesture recognition to enable natural, touch-free manipulation and exploration of historical artifacts in AR.
